# A LOTS OF GAME

A playful arcade collection with 200 mini-games built in HTML, CSS, and JavaScript.

## Run locally

1. Open `index.html` in a browser, or
2. Serve the folder with a local static server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Included

- 200 mini-game cards
- neon glassmorphism UI
- search and category filters
- playable arcade modes including memory, reaction, typing, number, quiz, pattern, and tic-tac-toe
- local score tracking

## Files

- `index.html` — main UI shell
- `style.css` — neon arcade styling
- `script.js` — game data and interactive logic

## Notes

This project is intentionally designed as a scalable arcade hub. It is easy to extend with more mini-games by adding new titles and template types in `script.js`.
